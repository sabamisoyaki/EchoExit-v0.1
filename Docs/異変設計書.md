# 666号扉 — 異変設計書

更新日: 2026-07-19  
状態: MVP実装7種（優先度A・B完了）を含む、製品版へ向けた基準設計

## 1. 異変設計の目的

異変は、単なる「前回との差分」やジャンプスケアではなく、プレイヤーが対象を疑い、自分で検証し、固有の儀式によって正体を認識するためのゲームオブジェクトです。

すべての異変は、次の体験を最低一つ成立させます。

1. 配置、形、音、挙動の弱い違和感から対象を疑う。
2. 見る、目を外す、近づく、離れる、叩く、立ち止まるなどを試す。
3. 正しい手順で、疑いが確信へ変わる現象を起こす。
4. 危険な場合は、その現象自体が逃走開始の合図になる。
5. 最後は異変ありとして後ろの扉を選ぶ。

通常オブジェクトへ同じ行動をしてもペナルティはなく、何も起きません。儀式は敵を倒す手段ではなく、異変を認識する手段です。

## 2. プレイヤーへ約束する設計原則

### 2.1 答えは隠すが、理不尽にはしない

- 儀式の説明文や正解手順は本編中に表示しない。
- 儀式前には、対象を疑うための弱い手掛かりを最低一つ用意する。
- 儀式成功後には、異変だと断定できる視覚または音の変化を必ず出す。
- 発動条件にランダムな成否を入れない。同じ異変、同じ操作なら毎回同じ結果になる。
- 入力受付時間を極端に短くしない。タイミング系でも基本受付幅は0.6秒以上とする。
- 認識前に、避けようのない捕獲やゲームオーバーを発生させない。

### 2.2 経験が知識になる

- 同じ異変の儀式は、フィールドやラウンドが変わっても同じとする。
- 見た目が同系統でも、異変IDが異なる場合は識別できる固有要素を残す。
- EditModeでは名前だけを表示し、手順説明は表示しない。安全に試せることで経験学習を成立させる。
- 異変図鑑、正解ログ、未発見通知は設けない。

### 2.3 怖さと操作可能性を両立する

- 追跡開始時は、音と動きによる明確な開始合図を出す。
- 危険な異変には最低1.2秒の攻撃開始猶予を設ける。
- 追跡中に全面を覆うUIは表示しない。認識表示は視界を妨げない短いバナーにする。
- 通常設定では、直線上の追跡速度をプレイヤー移動速度の75%以下にする。
- 捕獲判定は見た目より大きくしない。

## 3. 内部分類と危険度

分類と危険度は抽選、検証、難易度調整に使う内部情報です。本編のプレイヤーには表示しません。

### 3.1 挙動分類

| コード | 分類 | 内容 |
|---|---|---|
| `P` | 現象型 | 儀式後に見た目や音が変化するが、プレイヤーへ危害を加えない |
| `R` | 反応型 | 視線、距離、音、移動へ反応して驚かせるが、直接のゲームオーバーにはしない |
| `H` | 追跡型 | 認識後に追跡・攻撃を開始し、出口までの逃走を発生させる |
| `E` | 終幕型 | 捕獲時に専用の特殊エンディングを発生させる |

`E`は他分類へ追加する性質として扱います。たとえば、追跡して特殊エンディングを持つ異変は`H/E`です。

### 3.2 危険度

| 段階 | 内部名 | 設計基準 |
|---|---|---|
| `D0` | 無害 | 逃走不要。観察だけで最後まで確認できる |
| `D1` | 警戒 | 接近、急な音、短い接触反応はあるが捕獲しない |
| `D2` | 危険 | 認識後に捕獲能力を持つ。通常の追跡異変 |
| `D3` | 致命 | 特殊ルールまたは特殊エンディングを持つ。公式後半ステージ限定 |

## 4. 異変の共通状態遷移

```text
休眠
  └─ 儀式条件の入力開始
       ├─ 条件失敗・中断 → 休眠または進捗リセット
       └─ 条件成立 → 認識現象
                       ├─ P/R型 → 現象完了
                       └─ H/E型 → 猶予 → 脅威開始
                                      ├─ 出口到達 → 逃走成功
                                      └─ 捕獲 → ゲームオーバー／特殊エンディング
```

- 認識現象が終わっても、そのラウンドは「異変あり」のままです。
- 穏やかな異変をすべて認識することは、扉を選ぶ必須条件ではありません。
- 攻撃的異変から逃げ切った後も、後ろの扉を操作して判断を確定します。
- 複数異変ラウンドでは、一つでも異変が存在すれば後ろが正解です。

## 5. 儀式を構成する基本条件

製品版では、少数の入力と条件を組み合わせて固有儀式を作ります。異変ごとに専用コードを増やし続けず、条件を順番に評価できる構成を目指します。

| 条件 | 内容 | MVP |
|---|---|---|
| `Gaze` | 視線中央へ一定時間入れる | 実装済み |
| `LookAway` | 注視後に視線から外す | 実装済み |
| `Hit` | 対象を叩く | 実装済み |
| `EnterRadius` | 一定距離まで近づく | 実装済み |
| `ExitRadius` | 一度近づいた後、指定距離まで離れる | 追加予定 |
| `RemainStill` | 移動と視点操作を一定時間止める | 追加予定 |
| `MoveBackward` | 対象へ背を向けず後退する | 追加予定 |
| `Orbit` | 対象を見ながら一定角度回り込む | 追加予定 |
| `CrossThreshold` | 対象の前後や境界を通過する | 追加予定 |
| `AudioTiming` | 固有音の後、受付時間内に操作する | 追加予定 |
| `Sequence` | 複数条件を順序どおり満たす | 追加予定 |

新しい儀式は、原則として移動、視点、叩く、扉操作の範囲で作ります。異変専用の新しい操作ボタンは追加しません。

### 6.2 `ANM-001` 目を離した箱

| 項目 | 仕様 |
|---|---|
| 現在のアセットID | `changeColorBox` |
| 弱い手掛かり | 表面色の彩度が正常な箱よりわずかに高い。近くで低い電気音がする |
| 儀式 | 箱を1.5秒連続で注視し、その後1.0秒視線から外す |
| リセット | 1.5秒に達する前に目を外すと注視時間をリセット。再度見ると離脱時間をリセット |
| 認識現象 | 箱が赤へ変色し、背後から短い逆再生音が鳴る |
| 危険 | なし |
| 正常版 | 何秒見ても、何度目を外しても変化しない |

この異変は「見るだけでは終わらず、見た後に目を外す」というゲームの基本思想を教える役割を持ちます。序盤の公式ステージで最初に経験させます。

### 6.3 `ANM-002` 痩せる箱

| 項目 | 仕様 |
|---|---|
| 現在のアセットID | `anomaryShirinkBox` |
| 弱い手掛かり | 床との接触影が本体よりわずかに小さい |
| 儀式 | 2.5m以内へ接近する |
| 認識現象 | 約0.8秒かけて元サイズの8%まで縮み、見えなくなる |
| 復帰 | プレイヤーが5m以上離れると元サイズへ戻る |
| 危険 | なし |
| 正常版 | 接近・離脱しても大きさが変わらない |

一度縮み始めたら距離の中間帯で停止させず、最後まで縮小させます。フレームレートによって速度が変化してはいけません。

### 6.4 `ANM-003` 帰ってくる人形

| 項目 | 仕様 |
|---|---|
| 現在のアセットID | `DollPrefab` |
| 弱い手掛かり | 顔が出口ではなくプレイヤー初期位置を向いている。ごく小さな布擦れ音がする |
| 製品版の儀式 | 2.5m以内へ接近した後、6秒以内に4.5m以上まで離れる |
| MVPとの差 | 現在は接近した時点で成立する。`ExitRadius`追加時に製品版手順へ移行する |
| 認識現象 | 離脱成立時に0.3秒で黒く変色して消え、5秒後に同じ場所へ向きを変えて戻る |
| 将来強化 | 復帰時だけ顔または腕の姿勢を変える。プレイヤーの背後へ直接出現させない |
| 危険 | 捕獲なし。復帰時の音と姿勢で驚かせる |
| 正常版 | 接近しても変色、消失、音の変化がない |

驚かせることが目的ですが、消えた時点で追跡異変と誤認させすぎないよう、追跡開始音は使いません。

### 6.5 `ANM-004` 叩き起こし

| 項目 | 仕様 |
|---|---|
| 現在のアセットID | `bears` |
| 弱い手掛かり | 呼吸に合わせた微細な上下動。近距離で二人分の呼吸音が混ざる |
| 儀式 | 対象を一度叩く |
| 認識現象 | 頭部がプレイヤーへ向き、鋭い吸気音とともに立ち上がる |
| 猶予 | 認識から1.2秒間は移動しても捕獲しない |
| 追跡 | 基本速度2.8m/s、捕獲距離1.1m。最短経路でプレイヤーを追う |
| 逃走成功 | 後ろの出口へ到達し、扉を操作する |
| 捕獲 | 人形の列へ主人公が加わる専用終了演出へ分岐する |
| 正常版 | 何度叩いても動かず、追跡しない |

MVPの直線追跡は、複雑なフィールド導入時にNavMeshまたはフィールド別経路制御へ置き換えます。

### 6.6 `ANM-005` 席を数える椅子

- 基本オブジェクトは通常の椅子と同じにする。
- 弱い手掛かりとして、座面の下から一定間隔で一度だけ木を擦る音を出す。
- プレイヤーが椅子の背後を通過した後、4秒以内に座面を1秒見ると成立する。
- 成立すると、床へ落ちる椅子の影だけが1個、2個、3個と増える。本体は増やさない。
- 危険はなく、注視をやめると影が一斉にプレイヤー方向へ向く。
- `CrossThreshold → Gaze`の複合条件を導入する最初の異変とする。

### 6.7 `ANM-006` 呼吸する壁

- 壁面の継ぎ目と粉塵が、呼吸のような周期でわずかに動く。
- 3m以内へ近づき、壁を視界から外した状態で2.5秒静止すると成立する。
- 成立すると壁全体が一度だけ大きく膨らみ、プレイヤーの背後で息を吐く。
- 壁との距離を0.8m未満へ詰めた場合は、押し返すだけで捕獲しない。
- `EnterRadius → LookAway + RemainStill`を使うD1異変とする。

### 6.8 `ANM-007` 逆拍子時計

- 秒針音が6回ごとに一度欠落する。視覚上も秒針が一目盛り飛ぶ。
- 欠落した瞬間から0.6秒以内に時計を叩くと成立する。
- 成立すると針が高速で逆回転し、そのラウンド開始時刻を指して停止する。
- 失敗時は何も起こさず、次の6拍で再挑戦できる。
- 聴覚だけでも手順へ到達できるよう、字幕設定では`［時計の音が一拍途切れる］`と表示する。

### 6.9 `ANM-008` 一歩多い足音

- 見える本体を持たず、プレイヤーの足音へ一歩だけ余分な足音を重ねる。
- 余分な足音から0.8秒以内に移動を止め、2秒静止した後に振り返ると成立する。
- 成立すると、直前までいた位置に濡れた足跡と人型の影が一瞬だけ現れる。
- 捕獲はしない。音が主要手掛かりであることを教える中盤向け異変とする。
- 聴覚アクセシビリティ用字幕は方向を明示せず、音の存在と種類だけを示す。

### 6.10 `ANM-009` 退く監視者

- 人形またはマネキンを基本オブジェクトにする。
- 2.5m以内から視線を外さず、6m以上まで後退すると成立する。
- 視線が外れた場合は開始距離からやり直す。
- 成立すると首だけが180度回転し、その場へ崩れ落ちる。
- プレイヤーへ近づかないため捕獲はないが、後退経路に障害物を置かないことを配置条件にする。

### 6.11 `ANM-010` 泣くロッカー

- ロッカー内部から、4秒の静寂と3秒の泣き声を繰り返す。
- 静かな間に2.5m以内へ接近し、泣き声の間に5m以上へ離れる動作を2回成功させる。
- 成立すると扉が内側から開き、低い姿勢の影が追跡を始める。
- 追跡開始まで1.5秒の猶予を設ける。
- 配置時は、ロッカーから後ろの出口まで連続した逃走経路を必須にする。

### 6.12 `ANM-011` 鏡の遅刻

- 鏡像がプレイヤーより約0.12秒遅れて動く。注意深く見れば儀式前にも発見できる。
- 鏡を2秒見た後、180度振り返って3秒静止すると成立する。
- 成立すると鏡像だけが振り返らず、鏡の奥からこちらへ歩き始める。
- 1.5秒後に鏡面を抜けて追跡を開始する。
- 捕獲時は、主人公が鏡の内側へ残り、外側を別の主人公が歩き去る特殊エンディングへ分岐する。

### 6.13 `ANM-012` 六番目の影

- 人型本体は置かず、同じ人物の影だけが六つ目の光源下に現れる。
- フィールド内の三つの光だまりを、出口側から入口側へ逆順に通過すると成立する。
- 成立すると影が床から立ち上がり、照明が消えた区間だけを高速移動する。
- 明るい場所では停止するため、プレイヤーは光から光へ移動して出口を目指す。
- 捕獲時は主人公の影だけが次のラウンドへ残る特殊エンディングへ分岐する。
- フィールド構造と照明制御へ強く依存するため、ユーザー制作ステージでは使用不可とし、後半の公式専用異変にする。

## 7. 出現数と難易度

### 7.1 異変数

異変ありラウンドの個数抽選は、MVP上限3個を前提に次を初期値とします。

| 異変数 | 確率 |
|---:|---:|
| 1個 | 72% |
| 2個 | 23% |
| 3個 | 5% |

3個ラウンドは高難度用であり、序盤には出しません。複数存在しても、一つを認識した時点で後ろの扉を選ぶ判断は可能です。

### 7.2 連続正解数による抽選制御

| 連続正解 | 使用可能な危険度 | 追跡型の上限 |
|---:|---|---:|
| 0〜1 | D0、D1 | 0 |
| 2〜3 | D0〜D2 | 1 |
| 4〜5 | D0〜D2、公式限定でD3 | 1 |

- 一ラウンドへ追跡型は最大1体とする。
- D3と別の追跡型を同時配置しない。
- 追跡型と、その逃走経路を塞ぐ異変を同時配置しない。
- 同じ異変を2ラウンド連続で抽選しない。候補不足時のみ許可する。

## 8. 配置ルール

### 8.1 全異変共通

- プレイヤー初期位置から2.5m以内へ自動発動する異変を置かない。
- 前後の判断扉から2m以内へ異変本体を置かない。
- 儀式に必要な距離、視界、後退、回り込みの空間を確保する。
- 異変同士の中心距離は原則3m以上とする。
- 認識現象が壁や家具へ完全に隠れないことを確認する。
- 音を手掛かりにする異変同士は、同じ場所で音域と周期が競合しないようにする。

### 8.2 追跡型

- 発動地点から後ろの出口まで、幅1.2m以上の連続経路を確保する。
- 発動地点とプレイヤーの間に最低4秒分の逃走距離を確保する。
- 追跡AIが出口、壁、段差で停止しないことを検証する。
- 認識演出中は捕獲判定を無効にする。
- 出口操作中は0.5秒以内に判定を確定させ、操作硬直で捕獲させない。

## 9. 通常オブジェクトとの関係

- 原則として、各異変には同じ外観の通常版を用意する。
- 公式進行では、異変版を初登場させる前に通常版を最低一度見せる。
- 通常版は異変用スクリプト、タグ、マーカー、音源を無効にする。
- 通常版を叩く、見る、回り込む、接近する行動にはペナルティを設けない。
- 通常ラウンドでも配置を固定しすぎず、異変ではない自然な配置揺れを許可する。ただし異変の固有手掛かりは出さない。

## 10. EditModeの検証条件

### 10.1 保存時の必須検証

- Prefab IDが存在する。
- 異変数が上限以内である。
- 同じ追跡型が複数配置されていない。
- 公式専用異変がユーザー制作ステージへ含まれていない。
- 自動発動範囲がプレイヤー初期位置へ重なっていない。
- 前後の扉と異変の当たり判定が重なっていない。

### 10.2 公開前の通し検証

- 通常オブジェクトがすべてロードできる。
- 各儀式が少なくとも一度成立する。
- 認識後に前後の扉を操作できる。
- 追跡型がいる場合、後ろの出口まで逃走可能である。
- 捕獲と時間切れの後、タイトルまたは終了画面へ遷移できる。
- 180秒以内に、異変の有無を判断できる構造になっている。

JSONを直接読むと`isAnomaly`で答えが分かる問題は、MVPの手動共有では完全には防げません。将来は既存JSONを読み込める互換性を残したまま、回答部分を別ペイロードへ分離した`.666stage`コンテナを追加します。これは暗号学的な秘匿ではなく、偶発的なネタバレを防ぐための難読化として扱います。

## 11. 実装データ構造の方針

現在は`prefabId`から儀式プロファイルを割り当てています。異変数が増える前に、異変定義を配置JSONから分離します。

異変定義が持つ情報は次のとおりです。

| フィールド | 用途 |
|---|---|
| `anomalyId` | `ANM-001`形式の不変ID |
| `prefabId` | 表示オブジェクトの解決 |
| `behaviorClass` | P／R／H／E分類 |
| `dangerLevel` | D0〜D3 |
| `ritualSteps` | 条件と順序、時間、リセット規則 |
| `recognitionEffect` | 視覚、音、アニメーション |
| `threatProfile` | 追跡速度、猶予、捕獲距離、経路方式 |
| `endingId` | 専用エンディング。存在しない場合は共通捕獲 |
| `placementRules` | 必要空間、最小距離、競合タグ |
| `userStageAllowed` | ユーザー制作ステージで利用可能か |

ステージJSONは配置と異変IDだけを持ち、儀式の時間や危険度は持たせません。これにより、公式側で挙動を修正しても古いユーザーステージを読み続けられます。既存の`prefabId`だけを持つJSONは、現在の対応表から異変IDを補完して読み込みます。

## 13. 受入基準

個別異変は、次をすべて満たしたとき実装完了とします。

- 通常版では、すべての儀式候補操作に反応しない。
- 異変版では、仕様どおりの手順だけで100%発動する。
- 儀式を途中で失敗した場合、仕様どおりに再挑戦できる。
- 発動前の弱い手掛かりと、発動後の確定的な現象がある。
- 30fps、60fps、120fpsで発動時間が実用上同じである。
- キーボード／マウスとゲームパッドの両方で成立する。
- 必要な音へ字幕または視覚的代替を設定できる。
- 追跡型は認識演出中に捕獲せず、出口まで逃走可能である。
- 複数異変と同時配置しても、儀式条件が相互に破壊されない。
- EditModeで配置、保存、再読み込み、検証ができる。

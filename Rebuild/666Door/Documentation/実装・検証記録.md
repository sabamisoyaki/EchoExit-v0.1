## 3. 実行のしかた

### 3.1 Unity エディタを閉じているとき

`Rebuild/666Door` を作業ディレクトリにして実行します。エディタで開いたままだと、同じプロジェクトのバッチ実行はできません。

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.3.10f1\Editor\Unity.exe" -batchmode -projectPath . -runTests -testPlatform EditMode -testResults Artifacts/test-results.xml -logFile Artifacts/test.log
```

結果は `Artifacts/test-results.xml` に出ます。`<test-run>` の `total` / `passed` / `failed` と、`end-time` が今回の実行のものかを確かめてください。

### 3.2 Unity エディタを開いたまま

**Test Runner ウィンドウ**（Window → General → Test Runner → EditMode → Run All）が確実です。

`TestRunnerApi` から流すときは、**実行前に `PlayerSettings.runInBackground` を `true` にし、終わったら `false` に戻してください**。false のままだとエディタが裏にある間フレームが進まず、シーンを使う 4 件が `did not become ready` で失敗します（§1.2 の 2026-09-20 がこれです）。結果は `%USERPROFILE%\AppData\LocalLow\Door666\666号扉\TestResults.xml` に出ます。

Console で **Error Pause** がオンだと、エラーが 1 件出ただけでプレイモードが止まり、実時間待ちのテストが失敗します。テスト前に切ってください。

### 3.3 ビルド

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.3.10f1\Editor\Unity.exe" -batchmode -quit -projectPath . -executeMethod Door666.Editor.ProjectBootstrap.BuildWindows -logFile Artifacts/build.log
```

エディタからはメニューの **666号扉 → Windows ビルド** です。
